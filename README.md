# 냉장고 한 끼

냉장고에 남은 재료를 선택하면 그 재료를 활용할 수 있는 예시 메뉴를 보여줍니다.

## 사용 방법

1. 페이지에서 식재료를 1~3개 선택합니다.
2. **메뉴 찾아보기**를 눌러 선택한 재료를 활용하는 메뉴 2~3개를 확인합니다.
3. **다시 고르기**로 재료를 바꾸거나 **결과 공유하기**로 페이지를 공유합니다.

현재 달걀, 두부, 김치, 대파, 감자, 치즈, 참치, 양파, 버섯, 햄을 선택할 수 있습니다. 예시 메뉴가 부족한 조합은 선택한 재료를 모두 쓰는 볶음 또는 부침 아이디어로 채웁니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도의 서버, 설치, 로그인, 데이터베이스 또는 유료 API가 필요하지 않습니다.

## 메뉴 내용 수정

- `index.html`의 `recipeExamples` 배열에서 예시 메뉴의 이름, 매칭 재료, 필요한 재료, 조리 아이디어를 수정합니다.
- `createFlexibleRecipes()` 함수에서 예시 메뉴가 부족할 때 표시되는 범용 볶음·부침 메뉴를 수정합니다.
- 현재 메뉴는 체험을 위한 예시이며 푸드민의 실제 레시피가 아닙니다. 실제 레시피를 반영할 때는 해당 레시피의 재료와 조리 방법으로 위 내용을 교체하세요.

이 페이지는 선택한 재료와 메뉴 데이터를 비교하는 정적 JavaScript 로직으로 동작합니다. AI 모델이나 실시간 냉장고 분석 기능은 사용하지 않습니다.
